No.2. pwd: buat cek posisi saat ini.
ls: menampilkan daftar seluruh le dan folder yang ada di dalam direktori saat ini.
cd: untuk berpindah direktori.
mkdir: untuk membuat folder.
touch: untuk membuat file.

No.3. - Absoluth path adalah alamat lengkap dari root, menunjukkan lokasi yang sama dari mana pun kamu berada.  
 Relatif path adalah dimulai berdasarkan lokasi direktori saat ini, lebih ringkas,namun hasilnya bergantung pada posisi kamu berada.

      - ~: menunjukan direktori home pengguna saat ini.
        .: menunjukan direktori saat ini.
        ..: menunjukan direktori satu tingkat di atas direktori saat ini.

      - perintah rm -r akan menghapus folder beserta seluruh isi sub subfolder didalam nya.
        perintah ini harus digunakan dengan hati-hati karena File yang dihapus tidak akan masuk ke Recycle Bin dan tidak dapat dipulihkan dengan cara biasa.
